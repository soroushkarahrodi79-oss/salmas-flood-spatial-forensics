# Cartographic standard

Every publication map must state the decision supported, analytical date/period, evidence class and a prohibited interpretation.

Required elements:

- descriptive title and observation-status language;
- semantically honest legend;
- scale bar and north indication when direction is not obvious;
- CRS and units;
- data-source attribution and code commit used to generate the figure;
- uncertainty statement in the map body or caption;
- Persian names in Persian script alongside English where relevant;
- right-to-left shaping for Persian and a Persian-capable open font (the reference scripts use DejaVu Sans plus explicit Arabic shaping; Noto Sans Arabic is an acceptable replacement);
- color-vision-deficiency-safe colors and readable grayscale structure.

Class colors use the Okabe–Ito family where possible:

| Class | Color guidance |
|---|---|
| Observed impact | vermilion with explicit source symbol |
| Probable flood-related change | blue with corroboration qualifier |
| Possible flood-related change | light blue or dashed boundary |
| Terrain-supported runoff pathway | cyan/blue line |
| Terrain susceptibility only | neutral grayscale terrain |
| Insufficient observation | gray hatch |
| Outside analytical support | white or muted boundary |

Do not use glowing flood polygons, decorative 3D perspective, unqualified red damage symbols, rainbow ramps or opacity that hides uncertainty. Candidate outlets and OSM crossings must use distinct symbols from observed impact.
